# SheepBrowse

A light native macOS web browser of the Sheep family: Apple's WebKit under a Chrome-style UI — tabs on top,
an address bar that searches Google — in the macOS 26/27 Liquid Glass look.

## Features
- Chrome-style tabs: drag to reorder or tear off, pin, mute, tab search (⇧⌘A), recently closed (⇧⌘T)
- Address bar with Google suggestions, history, favorites and open tabs
- Sleeping tabs free their memory; a built-in ad and tracker blocker
- Favorites bar and page with folders (import from Chrome), History, Downloads
- Saved passwords filled with Touch ID; strong password suggestions
- Certificates: trust a device's self-signed certificate once or for good (pinned by SHA-256)
- Private windows, page translation on the Mac, Sync of favorites, passwords and settings (end-to-end encrypted, in your own Google Drive)

About 1.2 GB of RAM for six busy tabs where Chrome took 4.1 GB on the same pages.
